# DIVA Evaluation Project Overview

This project evaluates the quality and reliability of responses generated by DIVA (Digitale Interessenvertretungsassistenz), an AI assistant developed at the University of Göttingen.

The aim is to investigate how different chatbot configurations affect answer quality and how well responses meet the expectations of different stakeholders.

## Research Questions

- How can the quality of DIVA's responses be evaluated systematically?
- Which configurations produce the best answers for different stakeholders?
- How much variability occurs between repeated runs of the same configuration?
- Are differences in evaluation scores statistically meaningful?

## Methods

The project will investigate automated LLM evaluation metrics and apply statistical methods to compare chatbot configurations.

The implementation will primarily use Python.

## Project Structure

- `src/`: evaluation pipeline and helper functions
- `analysis/`: statistical analyses and visualizations
- `results/`: approved evaluation outputs and figures
